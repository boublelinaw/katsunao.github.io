# KatsuNao 網站｜後台操作說明

這份說明教你怎麼**不寫程式**就能修改網站內容。全程只需要你的 GitHub 帳號。

---

## 一、第一次使用：開啟網站（只需做一次）

1. 到 GitHub 打開 repo：`boublelinaw/katsunao.github.io`
2. 點上方的 **Settings（設定）** → 左側選單 **Pages**
3. 在 **Build and deployment** 底下：
   - Source 選 **Deploy from a branch**
   - Branch 選 **main**，資料夾選 **/ (root)**，按 **Save**
4. 等 1～3 分鐘，網站就會出現在：
   `https://boublelinaw.github.io/katsunao.github.io/`

## 二、第一次使用：連接後台 Pages CMS（只需做一次）

1. 打開 <https://app.pagescms.org>
2. 按 **Sign in with GitHub**，用你的 GitHub 帳號登入
3. 依照畫面指示**安裝 Pages CMS 的 GitHub App**，選擇 `katsunao.github.io` 這個 repo
4. 回到 Pages CMS，點進 `katsunao.github.io`，選擇 **main** 分支
5. 左邊會出現中文選單，就代表成功了 🎉

> 🔒 **只有你能編輯**：後台的權限跟著 GitHub 走，只有 repo 擁有者（你）能登入修改。朋友打開網站只能看。

## 三、後台選單一覽

| 選單 | 可以改什麼 |
|---|---|
| ⚙️ 網站設定 | 書封文字、交往計時器、開場森林的句子、背景音樂、對話框預設頭貼、字體、頁尾 |
| 🏠 首頁：世界觀與入內須知 | 世界觀、入內須知、聯繫方式、同意按鈕的文字 |
| 📑 目錄 | 大標題、小標題、順序，以及每個標題連到哪一頁 |
| 📄 頁面 | 個人簡介、爆豪、小森、時間軸、關於兩人、創作相關……也可以新增頁面 |
| ✍️ 創作 | 你的圖文創作（每篇一個項目） |
| 🗂️ 創作分類 | 主線／節日／日常／AU、Paro（可以新增、改名、調整順序） |
| 🏷️ 創作標籤 | 主線、平行時空、高中、成年……（可以新增、改名、刪除） |

每次改完按右上角的 **Save（儲存）**，大約 **1～2 分鐘**後網站就會更新。重新整理網頁就能看到。

## 四、區塊：像 Notion 一樣組合內容

每個頁面、每篇創作都由「區塊」組成。在「內容區塊」的地方：

- 按 **＋ Add（新增）** → 選擇區塊種類
- 拖曳左邊的把手可以**調整順序**
- 按垃圾桶圖示可以**刪除**

| 區塊 | 用途 |
|---|---|
| 標題 | 大標題（有 ✦ 記號）或小標題 |
| 段落文字 | 一般內文，可以用粗體、清單、連結，也能直接插入圖片 |
| 資料表 | 「生日：0420」這種「項目：內容」的表格 |
| 雷達圖 | Hero's Status。項目有幾個就是幾邊形；可以放好幾張並排（例如高中／成年） |
| 引言／代表句 | 置中、加上「」的一句話 |
| 提示框 | 有底色的框框，可選火光橘／葉綠／木棕 |
| 摺疊區塊 | 點一下才展開的內容 |
| 訊息對話 | 頭貼＋對話框，左邊爆豪、右邊小森 |
| 時間線節點 | 時間軸頁用：標題、副標、內文，加上可展開的「兩人對彼此的看法」對話 |
| 角色卡片 | 圖示、名字、簡介，加上「前往更多設定」按鈕 |
| 標籤列 | 「＃同班同學 ＃日久生情」這種標籤 |
| 圖片 | 單張圖片，可選寬度並加上說明 |
| 章節小標 | 小說裡「0629 · 1369 km」這種分段標題 |
| 分隔線 | 火花／葉子／細線 |

💡 只要在文字裡寫 **（待新增）**，網站上就會自動顯示成「待新增」的小標籤。

## 五、常用操作

### 新增一篇創作
1. 左側選 **✍️ 創作** → 右上角 **＋ Add entry**
2. 填寫標題、日期，選擇**分類**和**標籤**（可複選）
3. 上傳**預覽圖片**（沒有也沒關係，會自動顯示主題風格的預設圖）
4. 填寫**簡介**和**前言／預警**
5. 在「內文區塊」用「段落文字」「章節小標」「圖片」組合內文
6. 按 **Save**

### 新增或修改標籤、分類
左側選 **🏷️ 創作標籤** 或 **🗂️ 創作分類**，可以新增、改名，用「排序」數字決定顯示順序（數字小的在前）。改名後，已經用了這個標籤的文章會一起更新。

### 修改角色頁頂部的代表句
**📄 頁面** → 點選「爆豪 勝己」或「小森 尚」→ 填寫**代表句**欄位 → Save。

### 修改雷達圖
進入角色頁面 → 找到「雷達圖」區塊 → 在「圖表」裡可以新增或刪除一張圖，在「數值項目」裡可以增減項目、修改等級。

### 換掉狼／兔子頭貼
- 頁首圖示：頁面裡的「自訂頁首圖片」
- 角色卡片：卡片裡的「頭像圖片」
- 對話框：**⚙️ 網站設定 → 💬 對話框預設值**，或在單則訊息裡上傳頭貼

### 新增一個頁面並放進目錄
1. **📄 頁面** → **＋ Add entry**，填標題、加區塊 → Save
2. **📑 目錄** → 在大標題或小標題裡新增一項，在「點擊後前往的頁面」選剛剛建立的頁面 → Save

### 背景音樂
**⚙️ 網站設定 → 🎵 背景音樂**：
- 貼上 **YouTube 影片網址**，或
- 上傳 **mp3 音檔**（有上傳就優先使用音檔）

訪客按右下角的「音樂」按鈕才會播放。這是瀏覽器的規定，網站不能自動播出聲音。

### 交往計時器
**⚙️ 網站設定 → ⏳ 交往計時器**：可以修改起始時間（台北時間）、單位文字（中文／英文／不顯示），或整個關掉。

### 換字體
**⚙️ 網站設定 → 🔤 字體**：標題和內文可以分開選，有思源明體、思源黑體、霞鶩文楷、芫荽四種。
